# Public image percentage padding: partial support

The standalone compiler now emits percentage-padding images through ordinary outer/background and unpadded content owners. Runtime, renderer, schema and shared dependencies remain immutable. All four percentage insets stay on the original outer owner, preserving the containing-content-width basis. Content-box point dimensions remain exact on the inner owner while the outer accumulates padding; percentage dimensions are resolved once. The numerical guard and emitter share the actual outer stretch decision, so synthetic Auto preserves authored definite cross sizing and genuine automatic cross sizing still stretches.

## Admitted and unresolved contexts

Within the existing image profile (zero margins, default minima/maxima, bounded containing dimensions, legacy flex, start/stretch alignment), column packing admits intrinsic, fixed, percentage and automatic ratio dimensions; both box-sizing modes; mixed point/percentage insets; authored image bytes, fit and clipping. Content-box percentages require zero same-axis padding. The new percentage feature does not broaden codecs, own min/max/alignment wrappers, general nonimage content-box percentage padding or the existing gap/parent restrictions.

Rows diagnose percentage padding affecting ratio-derived automatic width, and horizontal percentage padding on automatic outer width. This includes intrinsic/start images and content-box point widths turned into automatic outer widths. Definite border-box row widths and content-box fixed row widths with vertical-only percentage padding have bounded public evidence. Private evidence demonstrates missing horizontal parent contribution and incorrect following-tail placement in rejected contexts. No universal impossibility is claimed; an ordinary composition preserving the original containing width during intrinsic measurement remains unresolved.

The compile-only 1×8192 PNG test demonstrates finite content and padding components whose final outer sum overflows. The public compiler rejects it, accepts a comfortably finite counterpart, and never renders those extreme dimensions. Diagnostics recommend removing percentage padding or using a definite border-box width; the advice test covers vertical padding influencing ratio-derived row width.
