# Auto margins: retained static-alignment control

The second public CLI candidate still fails the complete corpus: 64 scenes, 512 frames, 440 geometry passes, 432 pixel passes, and 1024 successful clear checks. The authoritative driver exited 1. All 64 files reproduce exactly through the frozen CLI with equal parsed maps. This is retained failure evidence, not a support qualification; initial r1 evidence remains intact.

The candidate changes cross-axis auto margins to perpendicular safe-alignment wrappers and sets a static physical-start native main alignment for main-axis auto margins. Cross-margin cases pass. Reversed-main positive-space cases improve, but the static choice fails overflow placement: 72 frames fail geometry. Eight further frames pass geometry but fail the white descendant's local RGB gate, in `auto-margin-row-multiple-main` and `auto-margin-column-multiple-main`, frames 0/3/4/7. These fractional-boundary failures are retained without loosening thresholds.

Visual coverage is complete. The 110 distinct image pairs divide into 44 newly reviewed pairs and 66 exact full-RGBA matches to directly reviewed r1 pairs. Every newly reviewed pair was inspected on `new-visual-0.png` through `new-visual-40.png` in increments of four. Within-r2 exact repeats account for another 402 frames. Each transfer compares full image dimensions and decoded RGBA bytes independently for Chrome and native, and every frame appears once in the coverage partition. Eight redundant r2 reviews matching r1 are not counted again. There are no automated-only frames.

Visible geometry failures show reversed-main overflowing items shifted toward or beyond the opposite edge relative to Chrome. Passing cases show no additional visible divergence. The multiple-margin pixel-only failures involve narrow white descendant boundaries; their automated local RGB failures remain authoritative even where the contact-sheet difference is subtle.

It uses original/clone same-file resizing, translucent fills, a white descendant, and a following footer. It does not qualify wrapping, grids, arbitrary nesting or unrelated CSS combinations.
