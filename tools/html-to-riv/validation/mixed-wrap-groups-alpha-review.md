# Mixed-wrap line groups preserve tested translucent overlap

The translucent follow-up passes **16/16 geometry and pixel comparisons**, with **32 clear controls**, for the two mixed-reversal row profiles. All six distinct viewport pairs were visually inspected, and ten return/clone pairs exactly match reviewed counterparts. This addresses the specific blind spot in the opaque experiment: additional active copies could otherwise paint indistinguishably over the same opaque color.

The layout and gate composition are unchanged from [mixed-wrap-groups-review.md](mixed-wrap-groups-review.md). The three leaf colors are now `#ff7f5080`, `#ffd70060` and `#008080a0`, preserving three different alpha values. Original SolidColor records are cloned before their original layout paints are made transparent. Each copied record changes only its Fill parent ID; color values are not reconstructed from hardcoded RGB constants. This maintains authored alpha in all nine candidate foreground copies.

Both `row-reverse + wrap` and `row + wrap-reverse` match pinned Chrome while native line membership moves through two, one, three and two lines. Overlap colors over the navy parent and white background agree, including return resize and cloned instances. The result supports correct visible alpha composition for these tested states; it is not a mathematical proof of gate exclusivity for arbitrary geometry, precision, masks or opacity hierarchies.

The source asserts the actual object increase during output: 27 raw records become 159, or **132 added ordinary records**. An independent parser also counted the frozen opaque r1 outputs and obtained the same totals. The nine painted copies are only part of that overhead; the complete gate/rule/mask composition remains quadratic and needs a production resource policy before admission.

Artifacts live in `tools/html-to-riv/output/mixed-wrap-groups-alpha-r1/`; [mixed-wrap-groups-alpha-receipt.json](mixed-wrap-groups-alpha-receipt.json) binds exact sources, dependency and binary hashes, fixture inputs, immutable render receipt, visual sheets, ten full-image transfer proofs and two complete adapter reproductions. Each reproduction verifies exact RIV bytes and parsed source-map content. The immutable renderer uses rust-metal RasterOrdering against Chrome 153.0.8010.12. Raw driver public scope wording is overridden by the experimental manifest.

The positive 25 px line separation remains essential to the tested signal. Tiny/zero gate failures are preserved in the earlier primitive receipt. Column axes, unequal or independently aligned line anchors, nested painted containers, clip/opacity interaction, wider viewport coverage and compiler-facing diagnostics remain unqualified. This test targets the pinned Chrome fragment ordering already documented in the compiler evidence, not all normative CSS painting behavior.
