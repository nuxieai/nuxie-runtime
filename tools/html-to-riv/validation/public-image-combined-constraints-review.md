# Public combined opposite-axis image constraints: partial support

An image with one authored percentage preferred dimension and an automatic opposite dimension can now use point or percentage minima and maxima on that automatic dimension, including simultaneous and conflicting bounds. The emitted file retains an ordinary ratio owner. Both minimum components have explicit authored units, while an automatic-axis maximum causes an additional maximum equal to the authored preferred percentage. These complete bound vectors prevent unwanted native ratio transfer into the preferred dimension. The original percentage values remain on the original owner; runtime resizing determines their values and whether a minimum exceeds a maximum. No browser layout, runtime mutation, sidecar or host operation implements this behavior.

The admitted profile retains zero image padding, default bounds on the preferred axis, existing ordinary nonflexible image restrictions and bounded percentage bases. Automatic minima, preferred-axis bounds, genuine automatic cross stretch, image padding and insufficient containing-size bounds remain diagnosed. The finite native evidence covers rows and columns with flex-start alignment, both preferred axes, point/percentage combinations, minimum-wins conflicts and padded-parent percentage bases. It does not establish arbitrary image/flex/stretch combinations.

Numeric validation derives the ratio intermediate before clamping, resolves both automatic-axis bounds against the original parent content axis, and applies maximum then minimum. An overflowing minimum cannot hide behind a finite maximum. Final fit arithmetic is checked separately. Authored mixed-unit bounds are not reordered or folded at compilation because their ordering can change with parent dimensions.
