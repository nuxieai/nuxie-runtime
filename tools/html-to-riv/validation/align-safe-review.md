# Safe and logical item alignment

The compiler now admits `normal`, `start`, `end`, `self-start`, `self-end`, and `safe`/`unsafe` prefixes on positional `align-self` values in the existing horizontal LTR single-line box profile. The computed keyword identity survives inheritance; logical values are not permanently rewritten as physical aliases. `normal` stretches in this profile. Baseline remains unresolved and rejected. Writing modes and direction changes outside this profile are not admitted.

Safe center/end use the existing perpendicular layout wrapper. Ordinary auto margins absorb positive free space along the wrapper's main axis: both margins for center, physical-start margin for end. When the item overflows, these margins collapse to zero and physical-start justification supplies the safe fallback. Unsafe values retain ordinary center/end overflow. Start values use direct sizing. This adds no runtime code, wire fields or host behavior, and does not yet admit authored CSS auto margins generally. Wrapper overhead remains at most one LayoutComponent/style pair per centered/end-aligned item.

The 21-scene corpus covers four directions; small, oversized and intrinsic items; all positional names; inherited variables; percentage dimensions; min-size overflow; nested wrappers; and ordered alpha overlap. Independent Chrome computed-style assertions verify the expected alignment keywords before native comparisons. All 168 geometry/pixel frames and 336 clear controls pass on pinned Chrome153.0.8010.12 and the immutable rust-metal renderer. The same original and cloned file is resized without recompilation.

Visual review inspected29 full Chrome/native pairs across seven contact sheets. The remaining139 pairs are proven exact decoded RGBA crops or white extensions of those inspected references, independently for Chrome and native images. Oversized, responsive and inherited cases received additional direct viewport review. No visible divergence was found. Hashes and per-frame proofs are preserved in output/public-align-safe-r1/visual-transfer.json.

79 Rust tests and21 Node tests pass, including CLI/WASM byte parity for the new corpus and malformed-value rejection. TypeScript and the immutable source guard pass. The frozen compiler reproduces all21 scenes exactly, and232 prior fixtures retain identical Rive bytes and source maps. This byte regression does not expand prior rendering claims or erase the known fractional min/max pixel failure.
