# Image constraint investigation: first ordinary-file candidates

Public min/max image admission remains closed. The runtime and production compiler are unchanged from the completed percentage-padding checkpoint. These private experiments patch ordinary LayoutComponentStyle min/max fields onto accepted unconstrained source recipes; they preserve encoded image bytes and source identities. No browser measurement becomes an emitted value.

The direct outer-bound candidate has 13 cases and 104 actual native frames: 64 geometry, 64 pixel and 88 presence passes. Intrinsic min/max width fails because height stays64; padded border/content max-width fails because height is measured from the old content width; fixed width120 with automatic height and max-height40 unexpectedly becomes width60. Both fixed dimensions, fixed-axis ratio clamps, inconsistent width bounds, stretch max-width and percentage max-width supply the passing controls. The complete direct review covers39 pairs/65exact transfers on15original-resolution sheets.

The ratio-and-inner candidate reuses the same five failing requests with changed ordinary files. Giving intrinsic images an automatic height and aspect ratio repairs max-width, but not min-width. An explicit synthetic max-width120 prevents the max-height vector from shrinking authored width120. Each repaired case passes all8geometry/pixel/presence checks. Mirroring a converted point max-width on the padded inner ratio owner does not repair stale height. Combined:40frames,16geometry/16pixel/32presence passes. Its complete visual review covers15pairs/25exact transfers on7original-resolution sheets; no public qualification follows merely from these private passes.

The next discriminating work is source-normalized point constraints and a shared image sizing/bound plan. For constant point dimensions/bounds, compute the used content axis from authored values before ratio measurement, preserving numerical provenance and padding floors. This is source calculation, not browser-baked layout. Intrinsic opposing constraints need explicit ratio-preserving versus distortion arbitration; automatic-axis maxima must respect authored definite opposite sizes. Percentage bounds need a separate composition retaining their original containing basis, and padded/max clamping must influence the first measurement, not only the final inner layout.

`image-constraints-plan.md` supplies the full finite matrix and primary specification/source references. In particular, `Bounds::image` currently overwrites the automatic ratio axis after prior clamping, so public integration must carry image-specific bound arbitration through that step. Do not simply remove the blanket min/max diagnostic. Preserve all failed candidates and move to independent backlog work if no new testable composition remains.
