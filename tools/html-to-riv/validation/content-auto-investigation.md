# L10: content-derived auto flex basis

Status: experimental implementation in progress; not qualified. Frozen L09 publisher retains rejection; the working publisher now admits auto content basis for investigation.

## Evidence captured

`content-auto-cases.json` contains 33 initial scenes: all four flex directions, factors 1/1, 2/1, .25/.5 and 0/1, text and nested fixed-content boxes, plus the existing unequal-text-width reproducer. `content-auto-oracle.mjs` captures 99 Chromium reference viewports (240/390/768) using the exact authoring reset and embedded Inter font. Reference output is `output/playwright/html-to-riv/content-auto-oracle/oracle.json`; all 33 scenes currently reject with unsupported-flex-basis against the frozen L09 compiler. Inputs, stderr and compiler hash are preserved in `content-auto-initial/receipt.json` and adjacent files. Only the original reproducer at240 has been visually inspected so far; other reference screenshots await review.

## Implementation questions

`Style::resolve_flex` rejects auto basis when the main dimension is auto and either factor is positive. `Style::write` routes equal positive factors through Fill; unequal factors preserve the authored dimension and install the existing occurrence policy. Investigate extending the dimension-preserving path to equal factors with intrinsic auto basis. The text emitter also enables intrinsic row text only when grow is zero; growing text needs content measurement without losing post-distribution wrapping. These are source findings, not proof that changing either condition alone produces correct layout.

## Qualification contract

Target content-derived auto basis for text and nested supported layouts, with equal/unequal/partial factors, grow and shrink, all directions, min/max constraints, wrapping and indefinite available space. Keep percentage basis in indefinite containers separate (L11). Do not equate auto basis with the distinct CSS content keyword. Preserve existing reset min-width/min-height:0 semantics. Require tests of cascade and shorthand/longhand equivalence, checked host transport if needed, original/clone runtime resize against independent Chromium geometry, native/WASM parity, native and vector pixel comparison, actual visual review and full regression. The initial 33-scene matrix is a starting reproducer set, not complete qualification coverage.

The active L08/L09 full regression uses frozen binaries and the unchanged main fixture corpus. L10 fixtures remain separate until implemented and tested.
