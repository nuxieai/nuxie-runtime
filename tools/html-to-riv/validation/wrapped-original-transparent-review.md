# Transparent original paint observation correction

The original-paint observer initially required one draw command for every certified owner. The `original-contained-row-transparent` fixture showed that expectation was wrong: all eight original/clone frames passed browser/native pixels, but the observer reported `missing original paint/clip` because the fully transparent middle owner had no draw command.

The immutable source explains the observed omission. `SolidColor::render_opacity_changed` sets the mutator's VISIBLE flag only when effective color opacity is greater than zero (`shapes/paint/solid_color.rs:72`). `ShapePaintBehavior::should_draw` requires both paint visibility and mutator visibility (`shapes/paint/shape_paint.rs:46`). `LayoutComponent` skips paints for which `should_draw` is false (`layout_component.rs:1485`). The closed source certificate has no opacity/visibility transformations beyond the bound solid color, so an authored zero-alpha solid is the relevant exact condition. This is existing runtime behavior, not a compiler or runtime modification.

Actual frame-0 commands contain the white artboard background and the two nontransparent owner paints (`0xffeeee22`, `0x80ff6030`), with the expected rectangles/transforms. No `0x00000000` draw appears. All eight frames exhibit the same zero-alpha omission.

The corrected observer still checks the transparent owner's source/proof ownership, positive integral native geometry and nonoverlap with every other owner. It requires exactly one matching draw for each nonzero-alpha owner and no draw for each zero-alpha owner. It does not accept arbitrary missing or unexpected paint. Existing strict clipping, matrix, rectangle, color and unknown-command checks remain in force. The ordinary SolidColor record remains in the produced file; this correction concerns native command observation only.

Preserved initial evidence is `output/playwright/wrapped-original-resource-r1/original-observation/receipt.json` (eight failures), together with `observer-initial.py`. Corrected evidence is `original-observation-r2/receipt.json`, with `visual/coverage-r2.json`. The initial `visual/coverage.json` remains intact. Reobservation recomputed every sheet and required exact equality with the existing PNG bytes; it did not rewrite those images or review notes. No rendering or browser capture was repeated.

The corrected result is 72 command streams with zero failures, 56 original-paint frames with 440 owner checks, 944 integral-axis checks, 736 rounded scalar checks and 976 matching Chrome edge comparisons. Eight explicit `omittedTransparentOwners` entries record the native culling. The visual corpus remains 27 distinct pairs in 12 sheets with 45 exact transfers; direct inspection is recorded separately.

Negative controls remain per observed paint mode: eight for ordinary original paint, seven for mixed fallback and ten for transparent original paint. In addition to missing/duplicate paint, extra clips, wrong transforms/colors, stack/unknown commands and overlap, the transparent controls reject an unexpected zero-alpha draw and reject omission after changing the expected alpha to a nonzero value. The corrected receipt binds the immutable source files that justify this condition. This does not qualify general opacity inheritance, animation, visibility policies, arbitrary paint mutators or public CSS wrapping.
