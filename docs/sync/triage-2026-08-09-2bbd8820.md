## Commit evidence and boundaries

### S6-2 — legacy layout compatibility

The upstream file minor version moves from 7.2 to 7.3. Before evaluating
transformable layout behavior, files authored before 7.3 have stale layout
rotation/scale reset so previously ignored values do not suddenly collapse or
move content. This is an import-compatibility gate, not a cosmetic layout
change, and its old/new fixtures must land with the port.

### S6-3 — globals in scripts

Lua scripts can resolve global view models from the runtime instance. The same
commit also mirrors deferred path queries into the renderer behind an upstream
feature flag. Nuxie's global-VM scripting surface is active and should port;
the renderer query is separable and remains WATCH pending the deferred-session
adaptation.

### S6-5 and S6-6 — image sampling and image paint

S6-5 adds authored sampling filter/wrap choices on image assets with node-level
overrides and passes them into rendering, an active schema/runtime/API surface.
S6-6 starts image-backed paints but is explicitly incomplete upstream and its
GM is disabled. Treating the latter as WATCH avoids copying a partial native
renderer design before a wgpu contract and pixel oracle exist.

### S6-7 — scripting lifetime correctness

Module registration is sorted and retried while skipping unavailable modules,
and scripted-object disposal clears backpointers safely. Both affect active
Nuxie scripting ownership. Candidate C++/Luau 0.733 builds and executes this
surface, but the current corpus lacks the failure and teardown shapes.

### S6-8 and S6-9 — host, layout, and scroll

S6-8 moves deferred host/frame-sink behavior into shared runtime code and adds
an inline player. It extends the architecture already isolated in S5-6, so the
portable wgpu subset should be designed once rather than ported commit by
commit. S6-9 changes the product format and active runtime semantics: stored
x/y become offsets from solved layout positions, component origins become
anchors, every positioning constraint honors them, and virtualized scroll
buffering becomes authored state. These changes are gated on `.riv` 7.3.
