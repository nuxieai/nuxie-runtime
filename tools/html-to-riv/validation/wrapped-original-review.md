# Private original-paint optimization checkpoint

The compiler can now retain original paints when a whole-scene certificate proves that every visible box is integral and fits its independent slot on both axes. This eliminates the entire paint replica and ordering suffix. Unknown, overlapping or mixed eligibility keeps the previous ordered-integral and rounded paths. No runtime, renderer, schema, dependency or root build change is required.

The certificate owns the exact encoded base bytes, preventing reuse with changed geometry under the same IDs. The independent original-paint reader checks that certificate identity, the unchanged prefix and Fill/SolidColor ownership, and the absence of paint objects in the sizing span. Existing sizing, scalar, position and finite-domain proofs remain required. Tests cover containment, both directions, source identity, mutation rejection, fallback identity and exact budgets.

The frozen product build passes 450 Rust and 56 Node tests, native/WASM builds, TypeScript and the source guard. Public CLI and WASM binaries exactly match the integral checkpoint. All 80 prior recipes construct twice deterministically and retain identical scene/base bytes, maps and traces; their 640 native/Chrome frames transfer without rerendering. None of these 80 selects the new whole-scene path, so separate fixtures exercise it.

Nine new fixtures cover 1/3/8/34 owners, two mixed fallbacks, contained row/column wrapping, clipping and a transparent middle item. Fresh pinned Chrome/native capture passes all 72 geometry and pixel frames plus 144 alternate-clear controls.
